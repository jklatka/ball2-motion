A note on the measurements

Position is estimated by integrating the ball’s velocity. Acceleration is calculated from changes in velocity. These estimates can drift, and local slopes are sensitive to noise. Graph Y uses the ball’s Z data; graph Z uses its Y data. X and signs are unchanged.

Average slope = endpoint change ÷ elapsed time. Mean value is time-weighted. Peak is the value with the greatest magnitude, retaining its sign. Boundary values are interpolated.

Your trial stays in this browser while the page is open. Export CSV before refreshing or closing. The server relays live data without saving trials. A server restart may require a new pairing address.
